Welcome to the sample blog! This site is the test harness for **Panhinda**, a
plug-and-play CMS for React sites. The idea is simple: your visitors see a fast,
statically-rendered site, while you — the admin — get inline editing right on the page.

## What this demo shows

This particular build is a plain content-driven blog, so we can focus on the reading
experience first:

- Server-rendered pages (SSR) via Astro's Node adapter
- Markdown-based content collections
- A clean, minimal reading layout

## What comes next

Once the blog foundation is solid, the plan is to wrap select pieces of content in
Panhinda's `<Editable>` components. When you're logged in, dashed outlines appear around
those regions and you can edit them directly — no separate admin dashboard required.

Stay tuned. For now, click around and enjoy the posts.
